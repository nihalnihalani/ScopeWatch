Older start/deadline/duration advice below is superseded; historical timestamps and analytics windows remain evidence, not build gates.

This is a curated ScopeWatch build handoff assembled on 9 October 2026 from the `sponsor-winners-research` workspace. The original source repository is preserved. The new repository has its own Git history and project authority; historical read-only analysis briefs are not current operational instructions.

## Deliberate omissions

No credentials, `.env`, keychain/session cookies, OAuth tokens, private account exports, arbitrary command transcripts, full research cache, raw social scrape dumps, cloned historical entrant repositories, application runtime database or competition application source were copied. The selected reference bundle includes official pages/API schema/public rule snapshots, not entire vendor websites.

Akash receives no project effort, integration or prize strategy. Some dated historical research may mention technologies used by past entrants or the supplied event's full sponsor list; those mentions are archive context, not a reopened sponsor target. Where older research describes BoundaryProof or CrossedLine, the current ScopeWatch architecture/build plan governs.

Third-party snapshots retain their source attribution and acquisition history. Research authorship does not grant a new license over vendor documents, rule catalogs or historical entrants' work. This repository adds no blanket license over those materials. The repository is created private as a build handoff; reviewer/public access is an explicit submission step.

## Provenance and link changes

[IMPORT_MANIFEST.json](provenance/IMPORT_MANIFEST.json) maps original relative paths to packaged paths. It records original source SHA-256 and packaged SHA-256 separately. Authored local links were remapped for self-contained navigation; historical notices and portability corrections can make the packaged hash differ.

The original vendor/source manifests under `references/` retain their historical `.firecrawl/...` paths and original capture hashes as provenance. They are not claims those original directories exist in this repo. Use the import manifest and `references/README.md` for the packaged locations. Packaged derivative indexes may have normalized links; original capture hashes should be verified against their original artifacts, not blindly applied to a rewritten index.

[RESEARCH_LEDGER.json](docs/architecture/RESEARCH_LEDGER.json) preserves the source architecture audit's capture method and limitations. The offline checks only test the intended research fixtures; they do not execute the proposed SQL, native API, frontend, controller or state machine. Diagram rendering validates documentation artifacts, not the project.

## What remains event work

Actual application source, dependency lockfiles, account-native field/unit/identity proof, same evaluated credential, real SQL/equality/readback, native policy matching/application, genuine target/control effects, optional scanner finding or prompt influence, real benchmark measurements and the actual submission are absent. Build them now or anytime under current authorization, without a cutoff, preserve evidence and label failures/unknowns honestly.

The [repository review](docs/reviews/REPOSITORY_REVIEW.md) checks this handoff's completeness and portability. It cannot establish sponsor eligibility, prize stacking, novelty or live runtime behavior.
