# Scoped teammate briefs

> **Current execution policy:** [Start now or anytime, with no build cutoff](../../event/BUILD_AUTHORIZATION.md). The human reports that the event is already underway and public schedules are stale. Older start/deadline/duration advice below is superseded; historical timestamps and analytics windows remain evidence, not build gates.

The lead creates actual teammates with full model IDs, bounded tasks and owned paths. These are **spawn-content files**, not fake runtime team configuration or installed subagent definitions. [Master prompt](../BUILD_SCOPEWATCH.md) · [launch guide](../RUN_IN_CLAUDE_CODE.md).

- [Backend engineer](BACKEND_ENGINEER.md): Sonnet 5.5, evidence/SQL/journal/control.
- [Interface engineer](INTERFACE_ENGINEER.md): Sonnet 5.5, complete polished operator UI.
- [Acceptance engineer](ACCEPTANCE_ENGINEER.md): Sonnet 5.5, independent behavioral/browser checks.
- [Devil's advocate](DEVILS_ADVOCATE.md): Opus 5.5, plan and integrated critique.

At most three teammates run concurrently. Roles are staged; finished builders free review slots. The lead owns shared contracts/config/lockfiles and central state; workers write only their own report and assigned paths. Task statuses use supported pending/in_progress/completed values, with richer dispositions recorded as metadata.
